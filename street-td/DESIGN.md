# まちかどオーケストラ 仕様書

3 歳児が一人で遊ぶ、ストリートミュージシャン風の配置ゲーム（タワーディフェンスの一種）。
楽器キャラを舞台の台に並べ、通りを歩く人の「好きな楽器」に合わせて入れ替える。
観客が集まると新しい楽器が仲間になり、曲（ベートーヴェン 交響曲第 8 番 第 1 楽章の提示部）がだんだん厚くなる。

- 公開 URL: `https://sakanayuki.github.io/cc_orchestra_td/street-td/`
- 調整用: URL に `?fast` を付けると、仲間が音符 8 個で増える早送りモードになる

## 前提

| 項目 | 決定 |
|---|---|
| 遊ぶ人 | 3 歳児が一人で。文字は読めない前提で、ロゴと「おしまい」以外に文字を使わない |
| 端末 | スマホ縦向き。360×720 の仮想画面を端末に合わせて拡大縮小する |
| 負け | なし |
| クリアまで | 約 5 分（上手に遊ぶと約 4 分半で 10 体そろい、そのあと全体演奏。何もしなくても 5〜6 分） |
| 効果音 | なし。鳴るのは曲だけ |
| GUI | Material Design 3。UI 部品だけ M3、町・楽器・人はドット絵 |

## 楽器

10 体。1 番・2 番奏者の音は 1 本に混ぜてある（1 キャラ＝1 音源）。

| グループ | 色・形 | 楽器 |
|---|---|---|
| 弦楽器 | 赤 ● | バイオリン、ビオラ、チェロ、コントラバス |
| 木管楽器 | 緑 ▲ | フルート、オーボエ、クラリネット |
| 金管＋打楽器 | 黄 ★ | ホルン、トランペット、ティンパニ |
| （通行人のみ）虹色 | ♥ | どの楽器でも好き |

- ファゴットは入れない。クリア時の全体演奏（Full-Mix）でだけ聴こえる隠れキャラで、それまではトレイ右端に「？」のシルエットでいる。
- トランペットとファゴットの絵は、コードで描いた仮のドット絵（`tools/build_images.py`）。

## ルール

- 始まり: 楽器 3 体（バイオリン、フルートが台の上、ホルンが待機列）、台 2 つ。
- 台の数は常に「楽器の数 − 1」。最後の仲間が来た時だけ台がもう 1 つ増え、10 体全員が乗れる。
- 置き方: 待機列の楽器をタップ → 台をタップ。台に楽器がいれば交代する。
  - 待機列の楽器を選んでいる間は、その楽器の音を半分の音量で鳴らす。置ける台がそっと光る。
  - 何も選ばずに台の楽器をタップすると、跳ねて一瞬だけ音が大きくなる（状態は変わらない）。
- 通行人
  - 頭の上の M3 の吹き出しで、好きなグループを色＋形で示す。年齢・性別の見た目は好みと関係ない。
  - 好きな色の楽器が舞台のどこかにいれば立ち止まる（場所は関係ない）。虹色の人は何かが乗っていれば止まる。
  - 立ち止まった人は舞台の方を向く（後ろ姿）。拍手しながら「3 秒＋同じ色の楽器 1 体につき 1.5 秒（最大 9 秒）」聴き、1 秒ごとに音符がゲージに飛ぶ。最後に手を振って去る。好きな楽器を入れ替えても、その場では去らない。
  - 色が合わない人は、舞台の前だけゆっくり歩き、吹き出しが揺れる。その間に合う楽器を置けば立ち止まる。合わなくても悲しい演出はない。
  - 吹き出しの色の出方: 虹色 15%、休んでいる楽器の色（舞台にいない色を優先）40%、残りは舞台にいる色から均等。最初の 1 人は必ず休んでいる楽器の色。
- 観客ゲージ（M3 の太い linear progress）がいっぱいになると、新しい楽器が跳ねながら来て、光る新しい台に自分で乗る。乗った瞬間にその音が曲に加わる。ゲージの右端には次に来る楽器のシルエットを出す。
  - 仲間になる順番: ビオラ → オーボエ → トランペット → チェロ → クラリネット → ティンパニ → コントラバス
  - 1 体ぶんに必要な音符: 54, 60, 65, 71, 77, 82, 88（楽器が増えるほど観客が長く聴くので、約 40 秒ずつになるよう後ほど多くしている）
- 台の並び: 扇形のひな壇。前列中央から順に出てくる（前 4、中 3、後 3）。

## ヒント

指のアニメーションで「楽器をタップ → 台をタップ」を見せる。

- 最初の 1 回は、始まって 3 秒後に必ず出す。
- その後は、7 秒何も触らず、かつ色の合わない人が舞台の前に来ていて、合う楽器が待機列にいる時だけ出す。

## 音

- 素材は 1 曲 7 分の MIDI 再現音源（パート別 18 本＋全体ミックス）。冒頭の提示部 0〜89.790 秒だけを切り出して使う。89.790 秒で提示部の繰り返しに入るので、そこがループの繋ぎ目になる（相関で測定）。
- モノラル・22.05kHz。OGG Vorbis（約 40kbps）と MP3（48kbps）の両方を用意し、OGG が使えないブラウザは MP3。
- 全パートをサンプル単位で揃えて同時に鳴らし、パートごとの GainNode で音量だけ変える。台にいない楽器は 0。
- メモリを抑えるため AudioContext を 22.05kHz で作る（11 本を展開して約 87MB）。
- iPhone のマナーモードでも鳴るよう `navigator.audioSession.type = 'playback'` を設定（対応ブラウザのみ）。

## 始まりと終わり

- タイトル: 上に「まちかどオーケストラ」のロゴ（M3 の primary container）。後ろでは、指が楽器を配置していく無音のデモが動く。読み込み中は M3 の circular progress、読み込み後はタップを促すアイコン。画面のどこをタップしてもゲームと音が始まる。
- クリア（10 体が台に乗った時）: 曲の位置はそのまま全体演奏に切り替える。ファゴットが色付きになって舞台の前に出てきて、虹色の観客が大勢集まり、紙吹雪が舞う。提示部の最後まで流し、残りが 10 秒未満ならもう 1 周流す。最後の 2 秒でフェードアウト。演奏中にタップすると「おしまい」まで飛ばせる。
- おしまい: 11 体と観客（正面向きでバンザイ）の集合写真を M3 のカードに出し、音を止める。3 秒たってからタップするとタイトルに戻る。

## 一時停止

- 右上の M3 icon button（⏸）を 2 秒長押しすると、まわりの輪が満ちてから M3 のダイアログが開く（「つづける」「タイトルへ」）。短いタップでは何も起きない。
- タブを切り替えたり画面を消したりしたら音を止め、戻ったら続きから再開する。
- 途中経過は保存しない。

## Material Design 3

- 配色: 元の色 #8B5A2B から tonal spot 方式の考え方で作ったライトテーマ（`css/m3.css` の `--md-sys-color-*`）。グループの色（赤・緑・黄・虹）はこれとは別に固定。
- 書体: M PLUS Rounded 1c（Google Fonts から、使う文字だけを読み込む）。
- 使っている部品: linear progress、circular progress、icon button、filled／text button、dialog、card、surface container、elevation、state layer、emphasized easing。
- ライブラリは使わず、CSS で実装している。

## ファイル

```
street-td/
├─ index.html
├─ css/m3.css        M3 のトークンと部品
├─ css/style.css     画面のレイアウト
├─ js/config.js      設定値（調整はここ）
├─ js/audio.js       パートを揃えて鳴らす仕組み
├─ js/game.js        ゲームの中身
├─ js/sprites.js     通行人・指・音符・マーク・吹き出しのドット絵
├─ js/town.js        町の背景
├─ js/main.js        起動・画面遷移・一時停止
├─ assets/           加工済みの素材（コミットする）
└─ tools/            素材の加工スクリプト（公開しない）
    ├─ build_audio.sh    source/ → assets/audio（ffmpeg）
    └─ build_images.py   source/ → assets/img（Pillow, numpy）
```

元素材を差し替えたら、リポジトリのルートで次を実行して `assets/` を作り直す。

```sh
bash street-td/tools/build_audio.sh
python3 street-td/tools/build_images.py
```
